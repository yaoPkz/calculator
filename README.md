# Calculator

A simple calculator built with HTML, CSS, and JavaScript. This project was created as part of The Odin Project curriculum to practice JavaScript fundamentals, DOM manipulation, event handling, and basic programming logic.

## Features

- Perform basic arithmetic operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Interactive calculator interface
- Clear (AC) button to reset calculations
- Delete (DEL) button to remove the last input
- Decimal number support
- Prevents multiple operators from being entered consecutively
- Responsive button layout
- Handles long numbers to avoid display overflow

## Built With

- HTML5
- CSS3
- JavaScript

## What I Learned

While building this project, I practiced:

- Manipulating the DOM with JavaScript
- Handling user input through events
- Managing calculator state
- Creating reusable functions
- Working with conditional logic
- Debugging and handling edge cases

## Challenges

The biggest challenge was figuring out how to store numbers and operators correctly so the calculator could perform calculations in the correct order. I also worked on handling edge cases like repeated operators, decimals, and clearing the calculator state.
